Arah Visual — Sistem Absensi Pengajian

A spreadsheet replacement first, an app second. The visual system is built around three commitments: legibility for older users, information density so a full session fits with minimal scrolling, and color that means something — never decoration. Below is the system; scroll down to see the Absensi screen built on it.

Tipografi

Two families, both from IBM Plex — designed specifically for data interfaces. Plex Sans for labels and names, Plex Mono for any number or code-like value (row number, time, currency, IDs). This split gives instant visual hierarchy and tabular numerals align perfectly.

Aturan Sistem

  • Density first. 38px row height, hairline dividers — 17–18 rows visible without scrolling at 1280×800.
  • Sharp corners. 3px max border-radius. No soft consumer pill shapes — this is a serious tool.
  • Color = meaning. The four status colors appear nowhere else. Brand chrome stays neutral.
  • Tabular numerals everywhere. All times, donations, counts use Plex Mono so columns visually align.
  • No icons-as-decoration. Icons only where they replace a word the operator already knows.
  • Big tap/click targets. Status pills are 28px tall, 62px+ wide. Even on a touchpad with shaky hands.
