activity_records
Per-bulan status kegiatan
PKidint
FKreport_id→ monthly_reports
FKactivity_type_id→ activity_types
status'Belum'|'Terlaksana'
executed_datedate · nullable
attendee_countint · nullable
locationtext · nullable
┄FKsource_meeting_id→ meetings
UNIQUE(report_id, activity_type_id). Auto-fill depends on parent activity_types.source_kind: meeting sources fill from meetings table, session sources fill from sessions (≥1 attendance for the month). source_meeting_id tracks the meeting if relevant. Operator can override.

Key relationships
households 1 ─ N members   (one KK has many anggota)
households.head_member_id N ─ 1 members   (KK's kepala)
members N ─ 1 roles
sessions N ─ 1 session_types
attendance N ─ 1 sessions + members   (junction)
meetings M ─ N members   via meeting_attendees
circular_roster N ─ 1 members
vital_records N ─ 1 members (nullable for unregistered)
member_movements N ─ 1 members
member_changes N ─ 1 members
monthly_reports 1 ─ N family_visits, sick_records, activity_records
activity_records N ─ 1 activity_types
activity_records.source_meeting_id N ─ 1 meetings   (when source_kind=meeting)
activity_types.session_type_id N ─ 1 session_types   (when source_kind=session)
